# china-color-style · 中华传统色画风配色设计

一个**自包含**的 DSH 技能包：整个文件夹拷到任何地方都能直接用，不依赖外部路径。

**当前版本**：1.0.0 ｜ **数据规模**：384 色（24 节气 × 16 色），375 条带完整 CMYK+RGB，359 条带意象典故

---

## 二、怎么安装

**DSH 技能发现规则**：技能必须位于某个「技能根」下的一层子目录里，即 `<技能根>/china-color-style/SKILL.md`。
可用的技能根（按优先级）：

| 优先级 | 技能根 | 作用范围 |
|---|---|---|
| 100 | `<工作区>/.dsh/skills` | 只在该工作区生效（目录隐藏） |
| 400 | `<DSH_HOME>/skills`（默认 `~/.dsh/skills`） | **所有工作区**都生效 |

**两种装法：**

- **软链（推荐）**：把本文件夹放到你想放的位置，然后在技能根里建软链指向它。
  好处是只有一份文件，改完不用重新拷。
  ```bash
  ln -s /你的路径/china-color-style ~/.dsh/skills/china-color-style
  ```
- **直接拷贝**：把整个 `china-color-style` 文件夹复制进技能根。适合拷到别的机器。

放好后 DSH 会自动发现（有目录监视，通常无需重启）；用 `skill(name="china-color-style")` 可验证。

## 三、日常维护

只有一件事：**上游数据更新后刷新包内副本**。

```bash
node scripts/sync-data.mjs          # 从上游复制最新数据进 data/
node scripts/sync-data.mjs --check  # 只比对差异，不写入
```

上游位置默认在部署环境的项目目录里，可用环境变量覆盖：
`CHINA_COLOR_SRC`（色卡数据集）、`CHINA_KNOWLEDGE_SRC`（知识库）。
如果你是在别的机器上用这个包，没有上游也没关系——`data/` 已经是完整的一份，脚本只在你需要同步时才用。

## 四、数据可信度（引用前请读）

- 384 条颜色，与原书标称的 384 色一致；结构为 **24 节气 × 每章 16 色**
- **375 条**有完整 CMYK+RGB；其中 **19 条为推定补入**（序列对齐/孤儿观测法），依据（配对色名、印证书页）都写在 `colors.json` 的 `flags` 里，**可逐条追溯与推翻**
- **9 条**仍无完整色值（`暾玉 紫药 紫絜 鵻维 纁 缥练 驈騵 𫟞色 紫浩`）：索引与正文拼写不一致且自动配对证据不足，**宁可留空也不硬填**
- 独立校验：原书附录色谱与正文章节页对照，**341 条完全一致、仅 1 条不同**（即"葭灰"同名两色）
- 色值为原书**印刷数值**，`hex` 由印刷 RGB 直接换算，未做色彩管理，仅供屏幕预览
- 技能被要求：推荐到推定/未定色值时必须主动说明，且**不得四舍五入或重新推算**色值

## 五、三个脚本的边界

| 脚本 | 能做什么 | 不能做什么 |
|---|---|---|
| `extract-palette.mjs` | 精确提取 PNG 主色与占比 | **只支持 8 位非隔行 PNG**；JPEG/WebP 会明确报错，需转格式或改用视觉通道 |
| `match-colors.mjs` | 找最接近的库内传统色（CIELAB ΔE76） | ΔE76 未做 CIEDE2000 加权修正，适合"找最接近"而非严格色差判定 |
| `analyze-image.mjs` | 让支持看图的模型分析时代/风格/形制 | 模型给的 hex 是**目测估计**，不可当采样值；需 API 凭证 |

精确取色请用 `extract-palette.mjs` 或直接查 `data/colors.json`；要语义匹配（这个场景该用什么色）请读 `data/色卡.md` 里该色的故事。

## 六、出处与使用边界

数据提取自一本公开出版的中国传统色专著（297 页扫描件），四份知识库为联网检索整理并标注来源。
本包用于**本地学习、创作参考与风格设计**；技能被明确要求只做组织与引用，不整本复制原著内容。
