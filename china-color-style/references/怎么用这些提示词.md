# 怎么用这些提示词

## 一句话结论

**一条提示词 = 一张图。一条一条出，绝不能把几条贴在一起。**

每条提示词本身已经是完整指令（主体＋风格＋时代＋配色＋材质＋光影＋构图＋画幅），
贴两条以上，模型会把两个主体和两种风格混进同一张画里。

## 一、基本操作

| 你拿到的 | 怎么用 |
|---|---|
| `Positive:` 那段英文 | 贴进**正向提示词**框（有的工具叫"描述""prompt"） |
| `Negative:` 那段 | 贴进**负向提示词**框（有独立框的工具才贴；没有的见下面第三节） |
| 结尾的 `vertical 2:3` 等 | 是**画幅**。有的工具直接在界面上选比例，有的要写参数（见下） |
| 一套里的 ①②③④⑤ | 是**五张不同的图**，共用同一个世界与配色，不是一条提示词的五段 |

**同一套里先出哪张？** 先出 ①（主图/基调图）。它对整套的构图、光线、配色定调。
后面的 ②③④ 建议拿 ① 的成品当**参考图**（图生图 / 参考图 / 角色参考），
否则五张图的人物长相、光向、色调会各走各的，凑不成一套。

**最后那张灰度图（套一的⑤、套二的⑤、套三的⑤）不是成品**——它是自查用的：
把灰度图给任何人看，如果看不出主体和时代，说明这条提示词的构图还不够清楚，要回去改。

## 二、是不是必须全部出？

不是。三个用法都合理：

- **只要一张**：挑一条最贴合需求的直接出；
- **要一套**：按 ①→②③④ 的顺序出，用 ① 当参考图保持一致；
- **要选风格**：三套各出 1 张①号，比对后再决定深入哪一套——**这是最省成本的试法**。

## 三、不同工具的贴法不一样（重要）

| 工具 | 正向 | 负向 | 画幅 |
|---|---|---|---|
| **即梦 / 可灵等中文产品** | 先直接贴英文试；若效果差，把英文拆成中文描述（主体、场景、风格、配色各说一句） | UI 有负向框就贴，没有就**别管**，别把负向词塞进正向 | 界面选比例 |
| **Midjourney** | 贴正向 | 改成 `--no 词1 词2`（只列具体物件，不要写"no modern objects"这种含糊否定） | 末尾加 `--ar 2:3` |
| **Stable Diffusion 系** | 正向框 | 负向框 | 用分辨率设定比例（如 832×1216 ≈ 2:3） |
| **Gemini / Nano Banana 类** | 正向 | **通常没有负向框**：把负向改写成正向约束，例如"Use period-appropriate timber and ceramic objects; keep the image free of lettering." | 用自然语言说比例 |

**别做的事**：不要照搬 Stable Diffusion 的括号权重 `(词:1.3)` 到别的模型上——那通常不生效；
也不要把 `--ar`、`--seed` 当成风格词写进正文。

## 四、出图不对怎么改

**一次只改一个变量，并保留上一张对照。** 同时改风格、构图和配色，你无法判断是哪一项起了作用。

常见问题与改法：

| 现象 | 先改什么 |
|---|---|
| 风格串味（画出了别的朝代的味道） | 检查是否叠加了矛盾风格词；把时代证据写具体（服饰、建筑、器物），别只写"ancient Chinese" |
| 颜色不对 | 配色放进 `Palette:` 段而不是 `Style:` 段；色名＋对象绑定（"jade-green skirt"）比孤立色值更有效 |
| 色彩糊成一团 | 拉开明度差；主色与辅色明度差建议 15–30 个 HSL lightness 点 |
| 人物五张不一致 | 用参考图/角色参考，而不是指望 seed |
| 构图散 | 明确唯一焦点；缩略图测试——缩小后主体还看得清吗 |

**提醒**：seed 只能固定噪声初值，**不能保证风格或人物一致**；六位十六进制色值在多数模型里
只是普通文本，**不保证像素级还原**。想严格控色，请出图后在目标色彩空间对平涂区域采样，
必要时用蒙版重着色或后期调色。

## 五、迭代节奏（省时间的做法）

1. 挑 1 条 → 出 4 张 → 选最接近的一张
2. 只改那一张不满意的**一个**变量 → 再出 4 张
3. 满意后，用这张当参考图出同套其余几张
4. 整套齐了再看灰度自查：主体、锚点、留白三层是否清楚

不要一上来就把 15 条全出完——那是最贵的试错方式。
