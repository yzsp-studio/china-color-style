# 数据与知识索引

本文件是 `china-color-style` 技能的资产地图。

技能包是**自包含**的：技能要读的数据都放在包内 `data/`，因此整个文件夹可以拷到任何地方直接用。
包内副本由 `scripts/sync-data.mjs` 从上游刷新。

## 一、色卡数据集

位置：包内 `data/`（相对技能所在目录解析；可用 `CHINA_COLOR_DATA` 覆盖）。

| 文件 | 内容 |
|---|---|
| `colors.json` | **主数据源**。每条含 `name` 色名、`chapter` 所属节气、`cmyk`、`rgb`、`hex`、`pages` 书页、`flags` 疑点、`meaning` 意象原文、`votes` 校验票数、`read_deviation` 异读偏差 |
| `colors.csv` | 同上的表格版，便于人工浏览 |
| `色卡.md` | 按二十四节气排版的色卡，含每条的颜色故事（**给人看、也适合喂给模型做语义挑选**） |
| `书籍结构图.md` / `page-structure.json` | 297 页的类型分布、92 个章节页码范围、逐页明细。用于按页定位与引用出处 |
| `待复核清单.md` | 疑点清单：数值异读、生僻字异读建议、色名与色值语义校验提示 |
| `README.md`（包根目录） | 包内构成、安装方式、日常维护、脚本边界 |

> 提取过程的原始识别记录（`raw/*.jsonl`）与复现脚本（`tools/`）**不在本包内**——它们属于提取项目的证据链，
> 留在上游数据集目录里。本包只带技能运行时真正要读的文件。

### 数据规模与置信度（引用数据前请先读这一节）

- 共 **384 条**颜色，对应原书标称的 384 色；结构为 **24 节气 × 每章 16 色**。
- **375 条**有完整 CMYK + RGB。其中 **19 条是推定补入**（用序列对齐或孤儿观测法），
  每条在 `flags` 里写明了配对色名与印证书页，可逐条推翻。
- **9 条**仍无完整色值：`暾玉 紫药 紫絜 鵻维 纁 缥练 驈騵 𫟞色 紫浩`。索引与正文对这些色名的
  拼写不一致，且自动配对证据不足——**宁可留空也不硬填**。引用时须说明。
- 独立校验：原书附录色谱与正文章节页对照，**341 条完全一致、仅 1 条不同**（即"葭灰"同名两色）。
- 色值为**原书印刷数值**；`hex` 由印刷 RGB 直接换算，未做色彩管理，仅供屏幕预览。

## 三、技能自带脚本（确定性，不调用模型）

| 脚本 | 作用 | 边界 |
|---|---|---|
| `scripts/extract-palette.mjs <PNG>` | 用 zlib 自行解码 PNG 取主色，输出精确 hex 与占比 | **仅支持 8 位非隔行 PNG**；JPEG/WebP 会给出明确提示，需改用视觉通道或先转 PNG |
| `scripts/match-colors.mjs "#A1B2C3"` | 把任意色值映射到最近的库内传统色，输出 ΔE 与候选 | 距离用 ΔE76，未做 CIEDE2000 加权修正，适合"找最接近"而非严格色差判定 |
| `scripts/analyze-image.mjs <图片> ["追问"]` | 视觉通道：把图片转发给支持看图的模型，取回结构化分析 | 需要 API 凭证（环境变量或凭证文件）；模型给的 hex 是**目测估计**，不可当作采样值 |

## 四、两种颜色的取用顺序

1. **要精确色值** → 像素提取（`extract-palette.mjs`）或直接查 `colors.json`。
2. **要语义匹配**（"这个场景该用什么色"）→ 读 `色卡.md` 里该色的故事，选意象契合的。
3. **两者都要** → 先用语义选候选，再用 `match-colors.mjs` 验证它们在 Lab 空间确实分得开（避免配色糊成一团）。
