# 跨时代/跨风格混搭的融合方法论

> 用途：为“按时代与故事背景推荐画风配色”的 AI 绘图 skill 提供可执行知识库。
>
> 说明：文中“检索方法”指由来源直接支持的原则；“推断/建议”是基于这些原则为生成式绘图所做的操作化归纳。

## 0. 核心定义

1. **时代锚点**：能让观者迅速识别文化、时代或地域的少量高信息元素。
2. **风格变量**：可以被替换、现代化或夸张的材质、光线、构图、技术语汇。
3. **主风格**：决定画面的第一印象、形体语法和大多数面积。
4. **从风格**：提供冲突、更新或叙事转折，但不夺走主风格的识别权。
5. **统一媒介**：用同一套笔触、材质、边缘、光源和景深把异质元素放入一个世界。
6. **混搭不是贴纸**：目标是产生共同的视觉语法，而不是把两个关键词并排堆上去。

## 1. 混搭为什么会失败

### 1.1 符号堆砌

- **成因**：把“龙、宫灯、汉字、霓虹、芯片、飞车”等名词当作独立贴纸，未说明它们的功能关系。
- **识别方法**：遮住任何一个符号后，画面叙事仍完全不变；或每个元素都在争夺视觉中心。
- **修复**：先写一句“谁在什么社会系统中使用它”，再只保留能服务这句话的两至三个锚点。

### 1.2 时代错位

- **成因**：服饰、建筑、技术、社会制度分属不同年代，却没有架空历史、替代技术或贸易传播的解释。
- **识别方法**：逐项追问“这个材料/工具在该世界如何生产”；答不出时就是装饰性拼接。
- **修复**：声明 alternate history、retrofuturism 或“传统工艺被未来技术重新制造”，并让材料链一致。

### 1.3 视觉噪音

- **成因**：高饱和色过多、纹样密度均匀、每处都发光、文字与纹理重叠。
- **识别方法**：缩小到缩略图仍看不出主体；灰度图层级消失；边缘检测处处同样强。
- **修复**：设置大面积留白/暗部，减少纹样种类，规定仅一个主光源和一个霓虹强调色。

### 1.4 比例失调

- **成因**：传统纹样被放大成背景噪声，或科技细节细到无法读；锚点面积与信息量不匹配。
- **识别方法**：主体、锚点、环境的面积和视觉重量无法分级；观者先看到随机边角。
- **修复**：先做三块黑白剪影，确认主体占 45–60%，锚点占 10–20%，技术细节占 10–25%。

### 1.5 形体语法冲突

- **成因**：写意留白与硬边工业透视、平面壁画与写实镜头同时出现，却没有过渡层。
- **识别方法**：线条粗细、轮廓软硬、透视规则在同一物体内部反复跳变。
- **修复**：指定一种主形体语法；从风格只进入材质、局部结构或色光，不同时改变轮廓、透视和笔触。

### 1.6 质感断裂

- **成因**：人物像油画，建筑像 3D 塑料，纹样像矢量贴图，光线无法照在它们身上。
- **识别方法**：同一光源下高光方向、粗糙度、阴影软硬不同；边缘没有共同的空气透视。
- **修复**：规定统一媒介（例如“ink-and-mineral pigment with controlled digital bloom”），并给所有物体同一颗粒层。

### 1.7 时代滤镜替代设计

- **成因**：只添加 scanlines、颗粒、sepia 或 neon glow，未改变结构和叙事。
- **识别方法**：删除滤镜后，两个风格的关系没有变化。
- **修复**：让技术重新解释传统功能，例如牌楼成为数据闸门、卷轴成为可交互地图，而非只加发光。

### 1.8 “两边都不像”

- **成因**：传统元素被过度简化，现代元素也只剩抽象色块；没有任何可验证的出处或明确的未来机制。
- **识别方法**：专家认不出传统母题，科幻观者也认不出技术系统。
- **修复**：保留一个准确的传统形制/构图锚点与一个具体的技术机制；其余内容服从二者。

### 1.9 文化刻板化

- **成因**：用“东方神秘、红灯笼、功夫、龙”替代复杂历史；把某地、某朝代当作无差别装饰库。
- **识别方法**：提示词只有泛称，没有时间、地域、用途、阶层和材料说明。
- **修复**：补充“使用者、场景功能、时代范围、工艺来源”；避免把单一符号当成全部文化。

## 2. 可执行融合流程（核心）

### 步骤 1：拆解需求

- 问：故事发生的具体年代、地点和社会技术水平是什么？
- 问：用户说的风格是媒介（ink）、运动（cyberpunk）、审美（雅致）还是题材（宫殿）？
- 问：画面主体、动作、镜头距离和情绪是什么？
- 问：哪些词是必须出现，哪些只是灵感？
- 完成标准：写出一句包含“主体＋世界＋时代逻辑＋情绪”的画面命题。

### 步骤 2：提取锚点

- 问：哪一个形制一眼能证明传统来源？（建筑比例、服饰剪裁、器物轮廓、构图）
- 问：哪一种工艺最能证明时代？（矿物颜料、丝绸、漆、木构、金属铆接）
- 问：该锚点的历史用途和使用者是谁？
- 问：只保留两个锚点时，哪个必须留下？
- 完成标准：得到 2–3 个有出处、有功能、有尺度的锚点，不能只写“东方元素”。

### 步骤 3：分配主从

- 问：观者第一秒先读主体、时代还是技术？
- 问：主风格控制哪些层面：轮廓、构图、色彩、材质、光线？
- 问：从风格只改变哪两个层面？
- 问：是否有明确面积比例？
- 完成标准：写出“主风格控制 A/B/C；从风格只介入 D/E；面积比例为……”。

### 步骤 4：建立转换机制

- 问：传统器物在新世界承担什么新功能？
- 问：新技术如何被传统工艺制造、维护或理解？
- 问：有没有中间形态（旧材料＋新结构、旧纹样＋新界面）连接两端？
- 问：技术元素是否会改变人物行为或空间动线？
- 完成标准：至少写出三条“传统功能→未来功能”的因果转换，而非装饰替换。

### 步骤 5：统一构图与形体

- 问：主体的剪影能否在黑白中读懂？
- 问：传统构图是轴线、散点透视、长卷动线还是壁画分区？
- 问：现代构图的 HUD、广告牌、线路是否服从该动线？
- 问：线条、透视、边缘软硬是否规定统一？
- 完成标准：缩略图中主体、锚点、留白三层清楚；所有技术线条指向叙事焦点。

### 步骤 6：统一媒介

- 问：选择何种主媒介？（工笔、墨、水彩、壁画、摄影、3D）
- 问：从风格如何被翻译成该媒介的笔触或材质？
- 问：所有表面是否共享颗粒、反射、边缘和空气层？
- 问：后期特效是否限制在同一光学世界？
- 完成标准：删去“风格名”后，仅凭材质、边缘和光线仍看起来是同一幅作品。

### 步骤 7：设计配色与光源

- 问：主色是否来自传统材料/颜料，而不是泛称“国风色”？
- 问：霓虹色是否只承担信息层级或光源功能？
- 问：暗部、局部高光和反射色是否有明确来源？
- 问：灰度、色盲可读性和文字对比是否足够？
- 完成标准：列出 HEX、面积比例、主光源色温和反射规则。

### 步骤 8：校验与迭代

- 问：专家能否说出传统锚点及其用途？
- 问：普通观者能否说出主角和时代冲突？
- 问：删除 30% 细节后，叙事是否更清楚？
- 问：是否误用了宗教、等级或丧葬符号？
- 完成标准：通过第 7 节的自查表；一次只改一个变量并保留对照图。

## 3. 锚点选择原则

1. **形制优先于表面纹样**：建筑结构、衣领、器物比例比随机云纹更可靠。
2. **功能优先于名物**：说明谁使用、为何使用、如何制造；功能让锚点进入叙事。
3. **一主一辅**：一个时代锚点负责识别，一个工艺锚点负责触感，第三个元素最多作为小比例暗示。
4. **传统保留**：保留轮廓、比例、工艺逻辑、构图秩序和社会语境。
5. **现代化变量**：现代化照明、能源、界面、交通、服装材料和空间用途。
6. **不可同时漂白**：传统形制和未来机制至少各保留一项具体、可辨认的特征。
7. **避免两边都不像**：提示词中使用“based on historically grounded [form]”，同时指定“functional speculative technology”。
8. **层级分配建议（推断）**：识别锚点 10–20% 画面面积但 30–40% 视觉权重；技术细节 10–25%；留白/暗部至少 25%。
9. **锚点测试**：将锚点单独画成黑白剪影，询问不看标题能否猜出文化来源；不能则换锚点。

## 4. 配色融合方法

### 4.1 可复用比例

- **60/30/10（建议规则）**：60% 主色（传统底色/空间），30% 辅色（材质、服装、阴影），10% 点缀（霓虹、警示、眼睛或界面）。
- **70/20/10（低噪音）**：极简或雅致题材使用 70% 低饱和中性色、20% 传统色、10% 科技色。
- **45/35/20（强冲突）**：赛博朋克海报可提高科技色，但必须让 45% 暗部/主色维持主体。
- **光色规则（推断）**：点缀色只占 5–10% 的发光面积，溢光覆盖不超过 20%；否则霓虹成为主风格。

### 4.2 明度与饱和度

- 传统色做大面积时降低饱和度 15–30%，保留材料感；霓虹色用高饱和但窄色相范围。
- 主色与辅色明度差建议 15–30 个 HSL lightness points；焦点与背景至少相差约 30 points。
- 暗部不使用纯黑：用深靛、墨绿、深褐承接传统颜料。
- 高光统一为同一温度：暖传统底色配冷青霓虹，或冷底配暖朱砂，避免多组互相竞争的光源。

### 4.3 光源逻辑

- 先规定主光源（太阳、灯笼、月光、招牌或能量核心），再规定补光和反射。
- 霓虹不是“全物体发光”：只照亮朝向它的表面，边缘溢光随距离衰减。
- 传统金属、矿物颜料和漆面有不同粗糙度；不要统一成塑料高光。
- 使用同一雾、颗粒和色散层，让冷暖色在空气中相互染色。

## 5. 案例一：中华审美 × 赛博朋克

### 5.1 设计拆解

- **主风格**：中华审美的轴线、留白、青黛与朱砂、木构/院落空间。
- **从风格**：赛博朋克的湿润夜景、功能性霓虹、数据网络与机械义体。
- **锚点**：牌楼式城市门洞、漆木与青瓦、书法式招牌（文字只作抽象笔画，避免生成乱码）。
- **转换机制**：牌楼成为身份验证闸门；灯笼成为低功耗导航节点；卷轴成为可展开的城市数据地图。
- **构图**：中央轴线引导人物，左右建筑留出墨色负空间，线路沿屋檐而非随机铺满。

### 5.2 English prompt

```text
A cinematic cyberpunk city designed through historically grounded Chinese aesthetic principles, a lone courier standing beneath a monumental timber gateway with dark blue tiled roofs, red lacquer beams and restrained abstract calligraphic signage, the gateway functioning as a biometric data checkpoint, translucent silk coat with subtle jade fasteners, wet stone courtyard reflecting one turquoise holographic lantern, deep indigo night, cinnabar accents, mineral-pigment texture, controlled ink-like edges, axial composition, generous negative space, one cool cyan key light and warm red practical lights, atmospheric rain, functional cables following the roofline, coherent material physics, highly legible silhouette, sophisticated editorial concept art
```

### 5.3 中文对照与配色

- 中文释义：以有历史依据的中华审美原则设计的电影感赛博朋克城市；木构门楼、青瓦、朱漆梁柱和克制的抽象书法招牌；门楼作为生物识别数据关卡；丝质外衣、玉质扣件；一盏青绿色全息灯笼；湿石院落、轴线构图、充足留白、单一冷青主光与暖红实用光。
- 配色：主色深靛 #26324A 60%；辅色朱砂 #B63A32 与旧金 #D7B56D 30%；点缀青绿 #20E6D2 10%。
- 负面提示词：`random floating ornaments, excessive neon, multiple competing light sources, stereotypical oriental decoration, unreadable dense text, plastic materials, cluttered composition`。

## 6. 案例二：水墨 × 数字故障艺术

### 6.1 设计拆解

- **主风格**：水墨的墨分五色、虚实、留白、笔势和纸张吸水边。
- **从风格**：glitch 的压缩块、错位扫描线、数据丢失和重复帧。
- **锚点**：山水的远近层次与书写性线条；不使用随机“故障滤镜”覆盖全画面。
- **转换机制**：墨迹扩散模拟数据包丢失；山脊的断笔变成帧错位；留白成为不可加载的空区。

### 6.2 English prompt

```text
An expressive Chinese ink landscape transformed by purposeful digital glitch, layered mountains built from ink wash, dry-brush ridges and absorbent xuan-paper blooms, a solitary bridge as the narrative anchor, selected mountain contours displaced into RGB channel offsets and horizontal compression blocks, sparse magenta and electric blue data fragments only at the fault line, large untouched negative space, monochrome charcoal values, tactile paper grain, glitch as a localized failure of transmission rather than decoration, coherent soft atmospheric perspective, balanced asymmetrical composition, museum-quality contemporary media artwork
```

### 6.3 中文对照与配色

- 中文释义：以水墨山水、枯笔山脊、宣纸洇染构成主体；桥是叙事锚点；只有局部山体轮廓发生 RGB 错位和压缩块故障；大面积留白，故障是传输失败而非装饰。
- 配色：墨灰 #17191C 70%；纸白 #E5E0D5 与冷灰 #56606B 20%；洋红 #FF3B81/电蓝 #4C8DFF 共 10%，只在断裂线上出现。
- 负面提示词：`full-frame glitch, rainbow overload, photorealistic mountains, random digital stickers, loss of ink texture, noisy background`。

## 7. 案例三：宋代雅致 × 极简未来主义

### 7.1 设计拆解

- **主风格**：宋代审美的克制、器物比例、灰青釉、含蓄留白和文人空间。
- **从风格**：极简未来主义的无缝平面、隐藏式界面、轻量材料和少量几何光线。
- **锚点**：单件比例严谨的瓷器/案几、灰青釉色、室内轴线与窗景；不用泛化宫廷金色。
- **转换机制**：瓷器作为环境传感器；案几作为无屏控制台；窗棂投影变成低对比导航网格。

### 7.2 English prompt

```text
A serene Song-dynasty-inspired interior reimagined as restrained minimalist futurism, one precisely proportioned celadon vessel on a low wooden table, quiet grey-green glaze, pale plaster wall, framed garden view and generous empty space, the vessel discreetly serving as an environmental sensor, seamless matte surfaces, hidden interface shown only by a thin ambient light line, soft overcast daylight, no ornament overload, subtle asymmetrical balance, refined East Asian spatial rhythm, low contrast, tactile ceramic and wood, premium editorial architecture visualization
```

### 7.3 中文对照与配色

- 中文释义：克制的宋代灵感室内空间，单件比例严谨的灰青釉器物位于低案，器物兼作环境传感器；无缝哑光表面、隐藏界面、薄薄的环境光线、柔和阴天光、低对比和大留白。
- 配色：暖灰白 #D8D3C5 70%；灰青 #6D7B83 与木色 #B9A58A 20%；淡青光 #A7E8E0 10%。
- 负面提示词：`luxury gold palace, ornate patterns, glossy sci-fi chrome, strong neon, crowded furniture, dramatic contrast`。

## 8. 案例四：敦煌壁画 × 蒸汽朋克

### 8.1 设计拆解

- **主风格**：敦煌壁画的平面叙事、矿物颜料、赭红、石青、石绿、金色线描与飞动姿态。
- **从风格**：蒸汽朋克的黄铜、铆钉、压力表、齿轮和可见机械动力。
- **锚点**：壁画式分区构图、矿物颜料色块、飞天般的飘带运动（不挪用特定宗教仪轨）；机械系统必须可工作。
- **转换机制**：壁画中的云气转为蒸汽管路；莲花形结构转为散热阀（避免将宗教对象当普通零件，需设定世俗化虚构语境）；金线变为导热/导光线路。

### 8.2 English prompt

```text
A richly composed steampunk mural inspired by the material palette and flat narrative composition of Dunhuang wall painting, a fictional maintenance engineer crossing a terraced mechanical shrine-like power station, mineral pigments in ochre red, lapis blue and malachite green, gilded contour lines, flowing fabric ribbons translated into visible steam conduits, brass pressure gauges, believable riveted boilers and articulated gears, mural panels arranged in rhythmic registers, aged plaster texture, controlled patina, warm directional light from a furnace, respectful non-ritual fictional setting, no sacred icon treated as a decorative prop, high-detail concept illustration
```

### 8.3 中文对照与配色

- 中文释义：受敦煌壁画材质色盘与平面叙事构图启发的蒸汽朋克壁画；虚构维修工程师穿过分层机械能源站；赭红、石青、石绿矿物颜料和金线；飘带转译为蒸汽管路；黄铜仪表、可信铆接锅炉和齿轮；尊重的非仪式虚构场景。
- 配色：赭红 #8C3F2F 45%；石青/石绿 #47706B 与旧金 #D59B45 35%；蒸汽冷青 #C9E6D9 20%。冷青只用于蒸汽反光，不让它成为主光源。
- 负面提示词：`random religious symbols, exoticized fantasy, plastic gears, arbitrary gold everywhere, modern logo, photorealistic 3D rendering`。

## 9. 检索到的方法与本知识库推断

- **检索到**：跨文化设计研究强调要处理身份、语境和权力关系，而不是把文化当作可自由取用的视觉素材；可参阅 [Māori-besque: cross-cultural design and hyphenated identities](https://www.scilit.com/publications/2c84706955e1122d012d8bffab9c4975) 与 [Recognizing appropriate](https://journals.uc.edu/index.php/vl/article/download/5918/4782#3#1)。
- **检索到**：博物馆藏品说明适合用来核对器物年代、用途、形制和图案语境，例如大都会博物馆的 [清代龙纹器物](https://www.metmuseum.org/art/collection/search/42364#1) 与 [清代印章](https://www.metmuseum.org/art/collection/search/503765)。
- **检索到**：V&A 的 [Stein Collection](https://collections.vam.ac.uk/item/O136222/the-stein-collection-wooden-fragment-unknown/) 可作为敦煌材料、保存和跨地域传播研究入口。
- **检索到**：视觉层级应通过大小、对比、留白和一致性组织，NN/g 的 [Visual Design Fundamentals](https://www.nngroup.com/courses/visual-design/?lm=conduct-heuristic-evaluation&pt=youtubevideo) 可作为界面/海报层级的通用参考。
- **检索到**：glitch 艺术的讨论将错误、媒介故障和传输痕迹视为作品内容，而非单纯装饰；可参阅 [Rosa Menkman 相关介绍](https://en.m.wikipedia.org/wiki/User:Spinster/sandbox/Rosa_Menkman#1)。
- **检索到**：关于“中国风赛博朋克”的中文视觉语言讨论可参考 [中国风赛博朋克视觉语言探析](http://xueshu.qikan.com.cn/preview/1/16/4244464#1)；百科概览见 [赛博国风](https://baike.baidu.com/item/%E8%B5%9B%E5%8D%9A%E5%9B%BD%E9%A3%8E/68618647#1)。
- **推断**：60/30/10、10–20% 锚点面积、单主光源等是为生成模型提示词可执行性整理的工作规则，不是上述来源直接规定的历史定律。
- **推断**：每次只让从风格介入两个视觉层面，是降低模型风格漂移的提示词工程策略。

## 10. 伦理与识别度边界

1. **先查语境**：宗教、仪式、陵墓、法器、神像、经文不可只当纹样；核对其用途、禁忌和社群意见。
2. **龙纹等级**：龙的爪数、位置、服饰和器物等级在不同历史语境有差异；不确定时用“abstract cloud-dragon motif, non-ceremonial fictional context”，不要声称准确复原。
3. **丧葬色彩**：白、黑、素色和某些纸扎/挽联语汇可能带有哀悼含义；为商业娱乐图像改色前先检查故事是否涉及死亡。
4. **敦煌与宗教图像**：不要把菩萨、供养人或经变画人物拆成性感装饰或机械零件；应采用非仪式虚构人物和受材质启发的抽象构图。
5. **避免“东方化”**：不使用“mysterious oriental”这类把多种文化压扁的词；明确朝代、地区、媒介和功能。
6. **标注推测**：无法核实年代时写“inspired by / speculative / fictional”，不写“historically accurate”。
7. **共同创作**：面向现实社群发布时，邀请相关文化持有者审阅，尤其是宗教和少数族群符号。
8. **识别度边界**：至少一项传统形制准确可辨、至少一项新机制具体可解释；若只剩配色和滤镜，就不应标为该文化风格。

## 11. 评估方法：混搭成功自查清单

- [ ] 一句话能说清主体、时代、世界规则和情绪。
- [ ] 至少两个锚点有来源、用途和尺度。
- [ ] 主从关系明确，主风格占主要轮廓/构图/色彩面积。
- [ ] 从风格有功能转换，不是名词并列。
- [ ] 缩略图中主体仍可识别。
- [ ] 灰度图中有前中后景和视觉焦点。
- [ ] 传统色和科技色分别承担空间、材质、信息或光源功能。
- [ ] 只存在一个主光源，反射方向合理。
- [ ] 同一表面颗粒、边缘、景深和空气透视一致。
- [ ] 删除三成装饰后，叙事仍成立甚至更清楚。
- [ ] 专家可指出锚点的历史/工艺语境。
- [ ] 普通观者能说出至少一个“传统被如何重新解释”。
- [ ] 没有无依据的宗教、等级、丧葬或民族符号。
- [ ] 英文提示词包含 subject、anchor、transformation、medium、palette、lighting、negative prompt。
- [ ] 连续生成三张时，主锚点和光源保持稳定。
- **建议评分（推断）**：识别度 0–5、融合因果 0–5、层级 0–5、材质统一 0–5、伦理语境 0–5；低于 18 分返工，任何伦理项低于 4 分必须返工。

## 12. 给 skill 的推荐逻辑

### 12.1 决策顺序

1. 解析用户的朝代/地域词，并判断其是严格历史复原还是灵感借用。
2. 解析故事背景：年代、地点、阶层、用途、叙事冲突和情绪。
3. 选择一个主风格：它控制剪影、构图和大面积色彩。
4. 从可靠资料库提取 2–3 个传统锚点：形制＋工艺＋功能。
5. 选择一个现代/跨时代变量：只改材质、技术功能或光线中的一至两项。
6. 写出传统功能到新功能的转换机制，解决时代错位。
7. 按 60/30/10 或 70/20/10 生成 HEX 色板；规定明度、饱和度和主光源。
8. 统一媒介、线条、边缘、颗粒、景深与负面提示词。
9. 进行伦理检查，发现宗教/等级/丧葬风险就请求用户澄清或改为抽象化表达。
10. 输出英中提示词、配色表、锚点解释和可选变体；生成后用自查表评分。

### 12.2 文字版决策树

```text
用户输入“X 朝代的 Y 风格”
  ├─ 是否要求历史准确？
  │   ├─ 是：限定年代/地域/阶层 → 查证形制与材料 → 禁止无据跨时代物件
  │   └─ 否：标记 speculative/inspired by → 允许架空转换，但保留可辨锚点
  ├─ Y 是媒介、题材还是运动？
  │   ├─ 媒介：媒介做主风格 → 时代进入形制/色盘
  │   ├─ 题材：时代做主风格 → 题材进入功能转换
  │   └─ 运动：先定运动的构图/光线 → 时代提供锚点和材料
  ├─ 选锚点：形制 + 工艺 + 功能（最多 3 个）
  ├─ 选变量：技术/材质/界面/光线（最多 2 个）
  ├─ 能否写出“传统功能 → 新功能”？
  │   ├─ 否：回到锚点或询问用户故事机制
  │   └─ 是：继续构图、媒介和配色
  ├─ 是否存在宗教、等级、丧葬符号？
  │   ├─ 是：核对语境，必要时抽象化并告知用户
  │   └─ 否：继续
  └─ 输出：主从比例 → HEX 色板 → 英文提示词 → 负面词 → 自查评分
```

### 12.3 推荐输出模板

- **一句话命题**：`[主体] 在 [世界规则] 中，以 [传统锚点] 解决 [新功能/冲突]。`
- **锚点表**：元素｜历史语境｜画面位置｜面积｜是否现代化。
- **提示词顺序**：主体 → 场景与时代 → 传统锚点 → 功能转换 → 构图 → 媒介 → 配色 → 光源 → 质量词 → 负面词。
- **变体策略**：只改变一个变量（更传统/更未来/更克制/更戏剧化），保留锚点与光源以便比较。
